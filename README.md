# Networkwalks Week 1 – Wireshark SOC Project (Extra)

## Project Overview
This project documents my practical experience completing the Networkwalks Week 1 Wireshark SOC Project.

The project involved investigating six Security Operations Center (SOC) labs using Wireshark concepts and network traffic analysis techniques.

## Objectives
- Identify suspicious IP addresses.
- Analyse network traffic.
- Follow and reconstruct TCP streams.
- Identify HTTP plain-text credentials in a controlled lab.
- Detect repeated login attempts associated with brute-force activity.
- Investigate VoIP traffic and identify a scam call.

## Tools and Technologies
- Wireshark
- Web-based Wireshark SOC Labs
- Network traffic analysis

## Labs Completed

1. **Identify the Attacker's IP** – Investigated network traffic to identify the attacker's IP address.
2. **Follow TCP Stream 1** – Reconstructed a network conversation and examined transmitted data.
3. **Follow TCP Stream, Part 2** – Analysed another TCP conversation and investigated hidden data.
4. **HTTP Plain Text Credentials** – Investigated HTTP traffic for credentials transmitted in plain text.
5. **Catch the Brute Force Attacker** – Analysed repeated login attempts to identify suspicious activity.
6. **Catch the Call Scammer** – Investigated VoIP traffic and examined the suspicious call.
